# 냉장곰 기획서

자취생을 위한 귀여운 냉장고 관리 + 냉장고 털이 요리 앱. 곰 셰프(쿠키 타이머 캐릭터)가 냉장고를 지켜준다.
리서치와 근거: https://claude.ai/artifact/1pUkmMXVXzQHVrVswtFGB5

## 정해진 것 (2026-10-27)

- 이름: 냉장곰. 타깃: 자취생, 2030 1인 가구.
- 첫 버전은 AI와 서버 없이 만든다. 데이터는 폰에만 저장, 로그인 없음.
- 아이폰 TestFlight 먼저. 쿠키 타이머 출시 뒤에 본격 개발.
- 무료 출시. 수익화는 겸업 승인 뒤 (쿠키 타이머와 같은 규칙).

## 첫 버전 기능

1. **재료 목록**: 냉장 / 냉동 / 실온 탭. 기한이 급한 순서로 정렬.
2. **말로 넣기**: 냉장실·냉동실·실온 칸을 누르고 말하면 그 칸으로 들어간다(칸을 말할 필요 없음). 아래 큰 버튼으로 말하면 재료별 기본 칸으로 들어간다. 폰 내장 음성인식(expo-speech-recognition)으로 말을 글자로 바꾸고, 재료 사전과 날짜 규칙으로 나눈다.
   - 예: "두부 오늘 넣었고 소비기한 11월 5일, 대파 3일 전에 샀어"
   - 날짜 표현: 오늘, 어제, 그저께, N일 전, N일 뒤, 다음 주 O요일, M월 D일, M/D
   - "소비기한" / "유통기한"을 구분해서 저장. 말하지 않으면 소비기한으로 보고, 우유만 유통기한으로 본다.
   - 날짜를 말하지 않으면 품목별 기본 보관일수를 쓴다.
   - 저장 전에 확인 카드를 보여주고, 틀린 칸만 눌러 고친다.
3. **탭으로 넣기**: 자주 사는 재료 칩.
4. **소분 통**: 통 하나 = 항목 하나. 직접 찍은 사진, 이름, 들어간 재료, 넣은 날, 번호 스티커. 사진은 폰에만 저장.
   - 소분 통이 아닌 재료도 사진을 찍을 수 있고, 찍으면 그 사진이 그림 대신 보인다.
5. **기한과 경고** (보수적):
   - 먹을 수 있는 기한 = 다음 중 가장 빠른 날
     - 표시된 소비기한 (절대 늘리지 않는다)
     - 유통기한 제품(사실상 냉장 우유): 늘리지 않고 유통기한 그대로 (아래 확인 결과 참고)
     - 개봉·소분한 날 + 품목별 개봉 후 기본값
     - 날짜 표시가 없는 재료: 넣은 날 + 품목별 기본 보관일수
   - 노랑 "주의": 유통기한 지남, 먹을 수 있는 기한 전
   - 주황 "D-2 ~ 오늘까지": 먹을 수 있는 기한 2일 전부터
   - 빨강 "먹지 마세요": 먹을 수 있는 기한 지남
   - 냄새나 모양이 이상하면 날짜와 상관없이 버리라는 안내를 항상 함께 보여준다.
   - 기한 임박 알림은 폰 안에서 예약하는 로컬 알림.
6. **레시피 추천** (src/recommend.ts, 테스트 npm test): 앱에 미리 넣은 레시피(식약처 조리식품 레시피 DB + 직접 쓴 자취 레시피)와 나만의 레시피 중, 없는 재료가 1개 이하인 것만 보여준다. 먹을 수 있는 기한이 지난 재료는 있는 것으로 치지 않는다.
   - 정렬 순서: ① 먹을 수 있는 기한이 3일 이내인 재료를 쓰는 레시피 먼저, 더 급한 순 ② 같은 급함이면 내 레시피 먼저 ③ 없는 재료가 적은 순 ④ 냉장고 재료를 많이 쓰는 순
7. **오늘의 냉털**: 곰이 하루 1~3개 추천.
8. **나만의 레시피**: 이름, 재료(재료 사전에서 선택), 만드는 법. 기본 레시피와 똑같이 추천에 들어간다.
9. **대체식품**: 재료 사전에 대체표를 둔다 (예: 대파 → 쪽파, 양파 / 우유 → 두유). 재료가 없어도 대체품이 있으면 "대체 가능"으로 추천.

## 그림

필요한 그림 (대략):
- 재료 약 100개: 레시피 DB에서 자주 나오는 재료 순으로 고른다 (API 키를 받은 뒤 빈도를 센다).
- 종류별 기본 그림 약 12개: 잎채소, 뿌리채소, 버섯, 과일, 소고기, 돼지고기, 닭고기, 해산물, 유제품, 양념·소스, 가공식품(햄·어묵 등), 면·빵·떡
- 곰 장면 3~5개: 냉장고 문 여는 곰, 빈 냉장고, 다 먹었을 때 축하 등. 곰 몸과 표정은 쿠키 타이머 것을 그대로 쓴다.
- 앱 아이콘, 스토어 스크린샷
- 레시피 그림은 따로 그리지 않는다. 카드에는 재료 그림을 나란히 보여주고, 상세 화면에서는 식약처 DB의 완성 사진을 쓴다(제3자 저작권이 없는지 확인 후).

- 자주 쓰는 재료 약 100개를 쿠키 타이머 그림체로 직접 그린다 (src/Ingredients.tsx). 각 재료에 같은 작은 얼굴.
- 그림이 없는 재료는 종류별 기본 그림(채소, 고기, 생선, 유제품, 소스, 기타).
- 사용자가 사진을 찍으면 어떤 재료든 그 사진이 그림을 대신한다 (목록, 확인 카드, 레시피 어디서나). 사진을 지우면 다시 그림으로 돌아간다.
- 곰 캐릭터는 쿠키 타이머의 src/Character.tsx를 그대로 가져왔다.

## 확인 결과 (2026-10-27)

- 상표: KIPRIS 상표 탭에서 "냉장곰" 없음 (사용자 확인).
- 레시피 데이터: 공공데이터법 제3조 제4항은 공공기관이 영리적 이용도 금지·제한하지 못하게 한다. 단, 제3자 저작권(사진 등)이 들어간 데이터는 예외라서, 레시피 사진은 출처를 표시하고 문제가 있으면 빼는 구조로 만든다. 식약처 DB 페이지에는 별도 이용 조건이 없다. 농림부 레시피 데이터는 데이터셋 페이지를 찾지 못했다(냉장고터는날이 광고를 붙여 쓰고 있음).
- 소비기한 참고값: 식약처가 2024년 12월까지 1,159개 품목, 2025년 6월에 291개 품목을 더 공개했다. 다만 영업자용이고 "제조일부터 며칠" 기준이라, 제조일을 모르는 사용자에게 그대로 쓸 수 없다. 그래서 유통기한 제품(사실상 냉장 우유)은 늘리지 않고 유통기한을 그대로 쓴다.
- 개봉 후·품목별 기본 보관일수: 미국 농무부 FoodKeeper 데이터(CC0, 누구나 상업적으로 사용 가능)를 기본값으로 쓰고, 김치·두부처럼 없는 한국 재료는 따로 정한다. 값이 여러 개면 가장 짧은 값.
- 음성인식: 애플 음성인식은 한국어(ko-KR)를 지원한다. 기기 안 인식이 한국어도 되는지와 실제 품질은 아이폰에서 확인해야 한다.
